# Manual Krios

API prevista em [DEFINITIONS.md](DEFINITIONS.md). Trechos independentes; imports usuais omitidos. `krios` representa o pacote da biblioteca, cujo caminho de módulo ainda será definido. Exemplos com `return err` ficam em funções que retornam `error`.

## Configurar o banco

Escolha um driver e registre-o com import. Conexões abaixo são exemplos locais.

### PostgreSQL

```sh
go get github.com/jackc/pgx/v5/stdlib
```

```go
import _ "github.com/jackc/pgx/v5/stdlib"

cfg := krios.Config{
    Dialect: krios.Postgres,
    Driver:  "pgx",
    DSN:     "postgres://app:secret@localhost:5432/app?sslmode=disable",
    Timeout: 5 * time.Second,
}
```

Driver e DSN: [pgx/stdlib](https://pkg.go.dev/github.com/jackc/pgx/v5/stdlib).

### MySQL

```sh
go get github.com/go-sql-driver/mysql
```

```go
import _ "github.com/go-sql-driver/mysql"

cfg := krios.Config{
    Dialect: krios.MySQL,
    Driver:  "mysql",
    DSN:     "app:secret@tcp(localhost:3306)/app?parseTime=true&loc=UTC",
    Timeout: 5 * time.Second,
}
```

`parseTime=true` permite ler DATE/DATETIME como `time.Time`: [go-sql-driver/mysql](https://github.com/go-sql-driver/mysql#parsetime).

### SQLite

```sh
go get modernc.org/sqlite
```

```go
import _ "modernc.org/sqlite"

cfg := krios.Config{
    Dialect: krios.SQLite,
    Driver:  "sqlite",
    DSN:     "file:app.db?_pragma=foreign_keys(1)",
    Timeout: 5 * time.Second,
}
```

Arquivo e parâmetros de conexão: [modernc.org/sqlite](https://pkg.go.dev/modernc.org/sqlite#Driver.Open).

```go
// Timeout limita a abertura/ping, não cada consulta.
// Timeout == 0: usar o prazo do contexto.
// Timeout < 0: ErrInvalidConfig.
// Dialect gera SQL; Driver seleciona o driver; DSN configura a conexão.
```

### Incorporar e executar

```go
// Declaração no pacote da aplicação.
import "embed"

//go:embed migrations/*/*.sql
var migrationFiles embed.FS
```

```go
func migrate(ctx context.Context, cfg krios.Config, target int64) error {
    dir := "migrations/" + string(cfg.Dialect)

    return krios.Migrate(ctx, cfg, krios.MigrationConfig{
        TargetVersion: target,
        Files:         migrationFiles,
        Migrations: []krios.Migration{
            {
                Version: 1,
                Up:      []string{dir + "/001_users.up.sql"},
                Down:    []string{"migrations/common/001_users.down.sql"},
            },
            {
                Version: 2,
                Up:      []string{"migrations/common/002_orders.up.sql"},
                Down:    []string{"migrations/common/002_orders.down.sql"},
            },
        },
        AllowNonAtomic: cfg.Dialect == krios.MySQL, // DDL com commit implícito
    })
}
```

```go
// Executar antes de abrir a conexão da aplicação.
if err := migrate(ctx, cfg, 2); err != nil {
    return err
}

// Alternativas de destino, quando desejadas:
// migrate(ctx, cfg, 1): desfazer orders, manter users.
// migrate(ctx, cfg, 0): desfazer orders e depois users.
// Up/Down podem listar vários arquivos, em ordem explícita.
```

```text
Migrate: abre pool → bloqueia concorrência → valida → migra → libera → fecha.
Versões positivas e únicas; destino zero ou versão existente.
Histórico: migrations(version, checksum, applied_at).
Não editar arquivos já aplicados: checksum divergente bloqueia a execução.
Atômico: falha desfaz todas as etapas da chamada.
Não atômico: falha pode deixar mudanças; dirty bloqueia nova execução.
Recuperação dirty: inspeção/reparo manual; sem repetição automática.
```

```go
    return err

```

Pool existente, como alternativa:

```go
pool, err := sql.Open(cfg.Driver, cfg.DSN)
if err != nil {
    return err
}
defer pool.Close() // responsabilidade da aplicação

    return err
}

if err != nil {
    return err
}

```

## Transação e contexto

Todos os builders e comandos usam `tx`.

```go
func createUser(ctx context.Context, db *krios.DB) error {
    tx, err := db.Begin(ctx, nil)
    if err != nil {
        return err
    }
    defer tx.Rollback() // desfaz em caso de erro; após Commit, retorna ErrTxDone

    commandCtx, cancel := context.WithTimeout(ctx, 2*time.Second)
    defer cancel()

    _, err = tx.Insert(krios.Table("users")).
        Columns("name", "active").
        Values("John", true).
        Exec(commandCtx)
    if err != nil {
        return err
    }

    return tx.Commit()
}
```

```go
// Alternativa: opções explícitas, quando suportadas pelo banco/driver.
tx, err := db.Begin(ctx, &sql.TxOptions{
    Isolation: sql.LevelSerializable,
})
if err != nil {
    return err
}
defer tx.Rollback()
// Executar operações, consumir/fechar linhas, então tx.Commit().
// Compartilhar DB entre goroutines é permitido; compartilhar Tx não é.
```

## Ler resultados

Helper usado nos exemplos com as colunas `id` e `name`:

```go
type User struct {
    ID   int64
    Name string
}

func readUsers(rows *sql.Rows) ([]User, error) {
    defer rows.Close()
    users := make([]User, 0)
    for rows.Next() {
        var user User
        if err := rows.Scan(&user.ID, &user.Name); err != nil {
            return nil, err
        }
        users = append(users, user)
    }
    if err := rows.Err(); err != nil {
        return nil, err
    }
    if err := rows.Close(); err != nil {
        return nil, err
    }
    return users, nil
}
```

### Where e operadores

```go
filter := krios.Where(
    krios.Eq("active", true),
    krios.Or(
        krios.Eq("name", "John"),
        krios.And(krios.Gte("id", 10), krios.Lte("id", 20)),
    ),
)
query = query.Where(filter)
```

```go
// Catálogo: escolher os predicados necessários.
predicates := []krios.Predicate{
    krios.Eq("id", 1),
    krios.Ne("id", 2),
    krios.Lt("id", 10),
    krios.Lte("id", 10),
    krios.Gt("id", 1),
    krios.Gte("id", 1),
    krios.In("id", 1, 2, 3),
    krios.NotIn("id", 4, 5),
    krios.Like("name", "Jo%"),
    krios.NotLike("name", "%test%"),
    krios.IsNull("deleted_at"),
    krios.IsNotNull("created_at"),
    krios.Between("id", 1, 10),
    krios.NotBetween("id", 20, 30),
    krios.Gte("created_at", time.Now().UTC().Add(-24*time.Hour)),
}

// Eq("deleted_at", nil) → IS NULL; Ne(..., nil) → IS NOT NULL.
// In("id") → falso; NotIn("id") → verdadeiro.
// And(), Or(), Where() e On() vazios → erro.
// Eq("name", "u.name") compara com texto, não com coluna.
// Colunas: EqExpr(Column("u.id"), Column("o.user_id")).
// Outras comparações: NeExpr, LtExpr, LteExpr, GtExpr, GteExpr.
```

### Paginação e contagem

```go
rows, page, err := query.Paginate(0, 10).ExecPage(ctx) // offset, limite
if err != nil {
    return err
}
users, err := readUsers(rows)
if err != nil {
    return err
}

if err != nil {
    return err
}

// Paginate(10, 10): próxima faixa.
// Exec: linhas; ExecPage: linhas + total, exige Paginate.
// Count ignora ORDER BY/LIMIT/OFFSET; preserva filtros, DISTINCT e grupos.
```


### Join

```go
joined := tx.Select(krios.Table("users").As("u")).
    Columns(krios.Column("u.id"), krios.Column("u.name")).
    InnerJoin(krios.Table("orders").As("o"), krios.On(
        krios.EqExpr(krios.Column("u.id"), krios.Column("o.user_id")),

    Where(krios.Gte("o.total", 10000)).
    Distinct().
    OrderBy(krios.Asc("u.id"))

}
```

### Agregação e Having

```go
summary := tx.Select(krios.Table("orders")).
    Columns(
        krios.Column("user_id"),
        krios.Count("*").As("quantity"),
        krios.Sum("total").As("amount"),
    ).
    GroupBy("user_id").
    Having(krios.GtExpr(krios.Sum("total"), krios.Value(10000))).
    OrderBy(krios.Asc("user_id"))

rows, err := summary.Exec(ctx)
if err != nil {
    return err
}
defer rows.Close()
for rows.Next() {
    var userID, quantity, amount int64
    if err := rows.Scan(&userID, &quantity, &amount); err != nil {
        return err
    }
    fmt.Println(userID, quantity, amount)
}
if err := rows.Err(); err != nil {
    return err
}
if err := rows.Close(); err != nil {
    return err
}

// Outras expressões: Avg("total"), Min("total"), Max("total").
// Agregados que podem retornar NULL: Scan em sql.NullInt64/sql.NullFloat64.
```

### Returning

Uma execução alternativa ao INSERT anterior; depende do banco/versão.

```go
rows, err := tx.Insert(krios.Table("users")).
    Columns("name", "active").
    Values("John", true).
    Returning("id", "name").
    Query(ctx)
if err != nil {
    return err
}
inserted, err := readUsers(rows)
if err != nil {
    return err
}
fmt.Println(inserted)

// Returning + Exec → ErrInvalidQuery.
// Query sem Returning, em builder de escrita → ErrInvalidQuery.
// Returning sem suporte → ErrUnsupported.
```

## SQL direto

SQL PostgreSQL; para MySQL/SQLite, substituir os placeholders por `?` em ordem.

```sql
SELECT id, name FROM users WHERE active = $1 ORDER BY id;
INSERT INTO users (name, active) VALUES ($1, $2);
UPDATE users SET name = $1 WHERE id = $2;
DELETE FROM orders WHERE user_id = $1;
```

```go
rows, err := tx.Query(ctx,
    "SELECT id, name FROM users WHERE active = $1 ORDER BY id", true)
if err != nil {
    return err
}
users, err := readUsers(rows)
if err != nil {
    return err
}
fmt.Println(users)
```

```go
// PostgreSQL: instruções independentes, executadas separadamente.
if _, err := tx.Exec(ctx,
    "INSERT INTO users (name, active) VALUES ($1, $2)", "John", true); err != nil {
    return err
}
if _, err := tx.Exec(ctx,
    "UPDATE users SET name = $1 WHERE id = $2", "Jane", 1); err != nil {
    return err
}
if _, err := tx.Exec(ctx,
    "DELETE FROM orders WHERE user_id = $1", 1); err != nil {
    return err
}
```

```sql
-- MySQL/SQLite: mesmos valores enviados em argumentos separados.
SELECT id, name FROM users WHERE active = ? ORDER BY id;
INSERT INTO users (name, active) VALUES (?, ?);
UPDATE users SET name = ? WHERE id = ?;
DELETE FROM orders WHERE user_id = ?;
```

```go
// Exemplo MySQL/SQLite.
if _, err := tx.Exec(ctx,
    "UPDATE users SET name = ? WHERE id = ?", "Jane", 1); err != nil {
    return err
}

// Query: linhas, inclusive SQL com RETURNING.
// Exec: sql.Result, sem retorno de linhas.
// SQL direto não recebe validação de WHERE nem reescrita de placeholders.
// Nunca concatenar valores recebidos no texto SQL.
```

## Erros

```go
// Inspecionar o erro retornado antes de continuar; após falha, fazer rollback.
switch {
case errors.Is(err, krios.ErrInvalidConfig):
    // Configuração inválida.
case errors.Is(err, krios.ErrInvalidQuery):
    // Builder ou argumentos inválidos.
case errors.Is(err, krios.ErrMissingWhere):
    // UPDATE/DELETE sem restrição válida.
case errors.Is(err, krios.ErrUnsupported):
    // Recurso não suportado pelo banco/versão.
case errors.Is(err, krios.ErrMigrationDirty):
    // Inspecionar e reparar migração antes de tentar novamente.
case errors.Is(err, krios.ErrClosed):
    // Instância DB fechada.
case errors.Is(err, sql.ErrTxDone):
    // Transação já finalizada.
case errors.Is(err, sql.ErrNoRows):
    // First/Last sem resultado; erro recebido por Scan.
case errors.Is(err, context.DeadlineExceeded):
    // Prazo excedido.
case errors.Is(err, context.Canceled):
    // Contexto cancelado.
}
```
